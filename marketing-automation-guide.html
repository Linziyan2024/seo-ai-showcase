01

Make vs Zapier 工具定位

Make
視覺化流程設計，適合複雜的多步驟自動化。強項在於資料轉換與條件分支，操作學習曲線略高。
適合對象有邏輯思維的行銷人員
免費方案1,000 次操作 / 月
強項複雜流程、資料處理
介面視覺化拖拉
行銷最適場景內容自動分發、CRM 整合
Zapier
業界整合最廣（7,000+ 應用），設定簡單直覺。適合快速串接常用工具，不需要複雜邏輯的任務。
適合對象任何行銷人員，門檻最低
免費方案100 次任務 / 月
強項快速整合、工具數量多
介面線性步驟設定
行銷最適場景表單通知、社群同步發佈

關鍵設定邏輯說明

流程 5 · AI 內容批量產製——Claude API 呼叫設定
Make → HTTP Module → Claude API Make
// HTTP Request 設定 URL: https://api.anthropic.com/v1/messages Method: POST // Headers x-api-key: {{your_api_key}} anthropic-version: 2023-06-01 content-type: application/json // Body（JSON） { "model": "claude-sonnet-4-5", "max_tokens": 2000, "messages": [{ "role": "user", "content": "請為以下主題撰寫一篇 SEO 部落格文章： 主題：{{1.topic}} 目標關鍵字：{{1.keywords}} 字數：1000-1200 字 語氣：專業但易讀，適合 25-35 歲行銷人員 請包含：H2 小標、FAQ 區塊、結尾 CTA" }] }
把 Airtable 欄位用 {{1.topic}}、{{1.keywords}} 動態帶入，每次觸發都能生成對應主題的內容
流程 3 · 週報 AI 摘要——提示詞模板
Make → Claude API → 週報摘要生成 Make
// 週報摘要 Prompt（帶入 GA4 + 社群數據） "以下是本週行銷數據，請生成一份給主管的週報摘要（200 字以內）： 【網站數據】 - 總流量：{{ga4.sessions}} 次（較上週 {{ga4.change}}%） - 轉換率：{{ga4.conversion}}% - 熱門頁面：{{ga4.top_page}} 【社群數據】 - IG 觸及：{{ig.reach}} 人 - 互動率：{{ig.engagement_rate}}% - 新增粉絲：{{ig.new_followers}} 請： 1. 用 2-3 句話說明本週整體表現 2. 指出最值得關注的亮點或警訊 3. 給出下週建議行動方向（1 條即可） 語氣：簡潔、數據導向，不需要客套語"
動態變數用雙大括號帶入，Make 會自動將前面模組的輸出值填入對應位置
流程 1 · 跨平台貼文——Zapier Filter 設定邏輯
Zapier → Filter → 條件設定 Zapier
// Zapier Filter 條件（只在「狀態 = 待發佈」時繼續執行） 條件 1: 欄位: Status 運算子: (Text) Exactly matches 值: 待發佈 條件 2（AND）: 欄位: Scheduled_Date 運算子: (Date) Is before or on 值: Today // 不符合條件時：停止執行，不計入 Zapier 任務次數 // 注意：Zapier 免費版每月 100 次任務，善用 Filter 避免浪費
加上日期條件可避免提前填入的貼文被提前發出，是排程流程的基本防護設定
05

常見錯誤與解法

✗
Make 執行失敗，顯示「Error 400」
通常是 API 請求格式錯誤。檢查 JSON body 是否有多餘的逗號，或變數名稱拼錯。建議用 Make 的「Run once」模式逐步測試每個模組。
✗
Zapier 任務次數很快用完
免費版每月只有 100 次，建議全部加上 Filter 條件。或改用 Make 免費版（每月 1,000 次操作），對高頻流程更划算。
✗
Claude API 生成內容品質不穩定
在 Prompt 中加入「system 角色設定」和明確的輸出格式要求。避免用太短的 prompt——細節越多，輸出越穩定。
✗
社群 API 授權突然失效
Meta、Buffer 的 Access Token 有效期限不同，建議在 Make 開啟「Email on Error」通知，流程失敗時立即收到警報。

團隊導入自動化：分階段清單

🌱 第一週：評估與準備

盤點目前最耗時的重複性行銷工作（發文、回覆、整理數據）
確認需要串接的工具清單（Google Sheets、Slack、CRM）
建立免費的 Make 和 Zapier 帳號並熟悉介面
設定 Claude API Key（Anthropic Console）
選定第一個要自動化的流程（建議從「表單 → 通知」開始）

🔧 第二週：第一條流程上線

用「Run once」模式測試每個模組，確認資料正確傳遞
設定錯誤通知（Email on Error 或 Slack 警報）
建立測試用的假資料，避免影響正式資料
正式上線前，人工執行一次完整流程確認輸出正確
記錄流程設定截圖，建立內部文件

📈 第三至四週：擴展與優化

追蹤第一條流程的執行成功率與節省時間
逐步加入第二、三條流程
優化 Claude Prompt，確保 AI 輸出品質穩定
建立 Google Sheets 作為流程監控儀表板
向團隊分享自動化成效（省多少時間、多少次錯誤避免）

🏗 持續維護事項

每月檢查 API Token 是否過期
Make / Zapier 月度用量是否接近上限
有工具更新 API 版本時，更新對應設定
新加入的行銷人員有文件可以快速了解流程
每季重新評估哪些流程可以進一步優化
